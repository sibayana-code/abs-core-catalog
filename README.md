# Abs & core catalog

Home abs and core form guide. Bodyweight first; band, wheel, and a bar show up on later IDs.

Live page: https://sibayana-code.github.io/abs-core-catalog/

Match the kebab `ab-…` ID in the Gym log (same pattern as the [push-up catalog](https://sibayana-code.github.io/pushup-catalog/)). IDs are stable — do not rename them.

Examples:

`ab-plank 3x30s RIR 2 — ribs down, no sag`

`ab-deadbug 2x8/side RIR 2 — back stayed glued`

`ab-hangknee skipped — no bar, did ab-revcrunch 3x10`
